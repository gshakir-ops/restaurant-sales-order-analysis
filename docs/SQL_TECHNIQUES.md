# SQL Techniques Used

This project is built for **MySQL 8.0+**.

## Core SQL

- SELECT / WHERE
- GROUP BY / HAVING
- ORDER BY
- CASE expressions
- aggregate functions
- JOINs
- subqueries

## Analytical SQL

- CTEs
- window functions
- RANK
- LAG
- cumulative sums
- rolling averages
- percentage-of-total calculations

## Time Analysis

- HOUR
- DAYNAME / DAYOFWEEK
- DATE_FORMAT
- WEEKDAY
- date-based grouping

## Business Analysis

- revenue contribution
- matched-order AOV
- order-size distribution
- category mix
- menu-item ranking
- item-pair / basket analysis
- ABC/Pareto classification
- revenue concentration
- anomaly screening using standard deviation

## Data Quality

- duplicate detection
- NULL checks
- full-record duplicate checks
- referential-integrity checks
- missing-item impact analysis
- category validation
- date-range validation
- time validation
- price validation

## Design Principles

Advanced SQL is used only where it improves the business analysis. The project prioritizes readable, reproducible queries over complexity for its own sake.
