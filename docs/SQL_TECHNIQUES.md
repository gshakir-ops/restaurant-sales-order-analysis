# SQL Techniques Used

This project is built for **MySQL 8.0+**.

## Core SQL

- SELECT / WHERE
- GROUP BY / HAVING
- ORDER BY
- CASE expressions
- aggregate functions
- JOINs
- subqueries

## Analytical SQL

- CTEs
- window functions
- RANK
- ROW_NUMBER
- NTILE
- LAG
- cumulative sums
- rolling averages
- percentage-of-total calculations

## Time Analysis

- HOUR
- DAYNAME / DAYOFWEEK
- DATE_FORMAT
- WEEKDAY
- date-based grouping

## Business Analysis

- revenue contribution
- AOV
- order-size distribution
- category mix
- menu-item ranking
- item-pair / basket analysis
- ABC/Pareto classification
- revenue concentration
- anomaly screening using standard deviation

## Data Quality

- duplicate detection
- NULL checks
- referential-integrity checks
- date-range validation
- price validation

## Design Principles

The SQL is intentionally focused on business questions. Advanced functions are used where they improve the analysis rather than simply to demonstrate syntax.
